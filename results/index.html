How These Numbers Get Measured

The numbers behind this work come from a location-set capture. A defined list of towns and search terms gets checked in one dated pass, not a single search from one computer and not a promise of constant real time tracking.

That capture gets repeated on a schedule. Each re-run replaces the prior numbers with a new dated result rather than layering estimates on top of old ones.

Every figure carries the date it was measured, shown on the dashboard itself rather than asserted here without one.

Why isn't the ranking data shown directly on this page instead of linked out?

A copy-pasted number here would go stale the moment the dashboard updates, and a visitor would have no way to tell which version was current. Linking straight to the live source means there is only one number to check, and it is always the current one.
